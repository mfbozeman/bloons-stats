Welcome! This is a monorepo containing source code and documentation for both
an API and a frontend view to provide some useful displays of various stats.
If you're just interested in viewing the stats website, you can see it at
https://btd6stats.netlify.app, or you can see the code in the frontend/ directory.
Code and more thorough documentation for the API is in the stats-api/ directory.
